# Autoescuelas Novel — Albacete

Sitio web oficial de **Autoescuelas Novel S.L.** (Albacete, España).

## Estructura del Proyecto

- `index.html`: Landing page completa, optimizada y autocontenida (HTML5 + CSS3 + JS vanilla).
- `assets/`: Logotipo oficial, favicon, fotografías reales de la flota, pista propia y mural de alumnos aprobados.
- `.nojekyll`: Garantiza la entrega estática directa en GitHub Pages.
- `.github/workflows/deploy.yml`: Despliegue automático y seguro mediante GitHub Actions.

## Despliegue

Este repositorio está preparado para **GitHub Pages** (rama `main` vía GitHub Actions) o cualquier hosting estático (Cloudflare Pages, Vercel, Netlify).
